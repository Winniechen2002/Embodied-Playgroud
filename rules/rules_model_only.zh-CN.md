# Level 0：允许代码，不提供预置领域工具

当前目录任务采用冷启动尝试；禁止跨尝试记忆与轨迹继承。遵循[共同规则](rules.zh-CN.md)及所声明实验的尝试／资源预算。

权限版本：`2026-10-09-environment-l0-l3`。

L0 允许 Python 代码、标准库、NumPy 和 Pillow，可进行普通数值计算、图像裁剪与缩放、动作组织和反馈控制，也可自行实现动力学预测、逆运动学和运动规划。限制针对预置领域工具的调用，不禁止使用基础依赖自行实现算法。

<a id="section-2"></a>
## 输入与访问

允许读取公开任务目标与参数、RGB、相机标定、公开机器人信息和本体状态。发射器每回合的弹簧刚度及 N/m 单位属于公开信息。隐藏位姿、场景几何、接触、重置种子和私有评分诊断不属于 L0 输入。执行代码不授予读取仿真源码、资产、私有文件或原生句柄的权限。

<a id="section-3"></a>
## 不提供的工具

禁止调用预置动力学／仿真器、IK、motion planning 工具和领域库。不提供外部深度、分割、重建、跟踪、抓取／接触模型及额外预训练动作策略。L0 的网关工具授权列表为空。基础计算、基础图像处理和自行实现的算法仍被允许，可使用公开机器人数据。

<a id="section-4"></a>
## 环境边界

只有声明的机器人动作推进环境；客户端没有 reset、瞬移、直接状态写入、修改配置或评分器的能力。原生伺服、动作缩放及明确声明的辅助夹具属于环境。网关不代替客户端求解 IK，也不自动修复动作；非法动作被拒绝。

代码可保存并重放自身合规观测与动作。更高级别的特权轨迹或预置控制器不会因为复制进文件就变成 L0 输入。各任务的物理规则继续适用。

<a id="section-5"></a>
## 版本与范围

记录 `capability_level: 0` 和上述权限版本，区别于观测配置和任务难度。网关强制自身字段、资源与工具授权，不认证任意外部 Python 客户端使用的库。本次环境发布不实现模型 token 或图片读取额度计费，也不发布模型测试成绩。实验运行方可另加预算，不改变环境权限。历史记录保留原权限版本，不重新标注。
